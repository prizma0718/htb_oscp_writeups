A curated collection of **Hack The Box** and **Vulnlab** machine writeups compiled while earning my **OSCP+** certification. Each walkthrough documents the full attack chain—from initial service enumeration and vulnerability analysis to Active Directory lateral movement and privilege escalation—complete with exact commands, exploitation reasoning, and remediation notes.

## Repository Structure

* **[Windows & Active Directory Writeups](AD-Windows/)** — Kerberoasting, AS-REP Roasting, ACL abuse, GPP credentials, and domain privilege escalation
* **[Linux Writeups](Linux/)** — Web application exploitation, SUID/capabilities abuse, credential harvesting, and kernel/service escalation
* **[Starting Point Writeups](Starting-Point/)** — Foundational enumeration, SMB/FTP/SQL misconfigurations, and initial access methodology

Use this knowledge responsibly and only against systems you have explicit permission to test.
